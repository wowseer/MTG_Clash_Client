# forge-bridge

Java-Brücke zwischen MTG Clash (Godot/Rust) und der Forge-Regel-Engine.
Lizenz: **GPL-3.0** (siehe `LICENSE`), da sie Forge-Klassen verwendet.

- Bauen: `./build.sh` → `build/forge-bridge.jar` (Forge-Jar über `FORGE_JAR`)
- Von Hand starten: `./run.sh` (Forge-Ordner über `FORGE_DIR`)
- Testdecks: `testdecks/`

Protokoll und Einrichtung: [`../docs/Forge-Schnittstelle.md`](../docs/Forge-Schnittstelle.md)
